# ADR-029 — Bounded per-page OCR and explicit local VLM fallback

**Purpose:** Define D21 rendering/model trust boundaries, quality evidence and uncertainty semantics.

**Date:** 2026-10-18
**Status:** Accepted for localhost/one worker: 28 page/parser/kernel, 10 vision protocol, 12 DB/HTTP lifecycle and 4 metric/live-quality cases. Final full 641 passed in 66.51s, zero skipped. Retained synthetic evidence: clean/scan CER0, actual CORE table6/6 exact cells/rows, degraded OCR CER1.0 flagged review; English-only OCR/explicit always-review VLM scope.

P1 depends on D17 owned ready FDs/sandbox, D18 native PDF provenance and D19 response-lifetime admission. Estimate one or more milestones. Risks: hostile rendering, CPU/pixel/GPU exhaustion, model hallucination/instructions, uncertain reading order/tables and stale/deleted source. Reuse installed Poppler/Tesseract and existing CORE vision/mmproj, not a new service. Tesseract currently has eng/osd only; no claim of Vietnamese OCR accuracy. Runtime Pillow/pypdf already exist. No new runtime dependency/schema/credential.

Add authenticated `POST /files/{id}/ocr?page=1&mode=auto|ocr|vlm`, one source page per request. PDF page indices are one-based; images have page1 only. `auto` returns available native PDF text, otherwise Tesseract English OCR. Mixed pages may omit image text in native mode; report this and allow explicit OCR/VLM. `ocr` forces raster OCR; `vlm` explicitly sends a sanitized raster to the configured loopback CORE for text/table extraction. No implicit model call on upload or automatic escalation from low-confidence OCR. No history/tools/indexing/persistence or remote URLs.

Reuse D17 private read-only namespace sandbox. Verify PDF/image content again. Native PDF text uses pypdf; Poppler renders only the selected page, at most2048 pixels per side/4 million pixels. Pillow normalizes raster orientation/RGB and strips metadata. All source metadata including ICC is removed; sanitized PNG at most4 MiB enters OCR or VLM. Tesseract TSV supplies bounded word/line IDs and pixel boxes; table grid is not inferred by OCR. VLM returns schema-validated text/table rows/uncertain regions only; model instructions remain untrusted data.

Worker512 MiB RAM,8/9s per-process CPU,25s parent wall,32FD,zero core,8 MiB stdout; renderer/OCR child deadlines8/10s and no worker descendants survive timeout. Temporary parser output reuses the inherited anonymous regular stdout FD inside read-only `/tmp`; no user path or credential mount. Input image20M-pixel D17 bound, rendered4M-pixel, text64 KiB,5000 words,20 tables/100 rows/20 cells and read JSON1 MiB including provenance. All bounds reject rather than truncate.

OCR score is character-weighted mean Tesseract word score (0–100), explicitly not calibrated correctness probability. Missing text or score<85 requires review. Always report English-only, ordering/structure and score limitations. Native text has no OCR score; VLM has no calibrated confidence and always requires review, including apparently correct tables. Blank/low-quality pages report uncertainty, never invented certainty. Pixel coordinates refer to normalized rendered pixels, not PDF points.

One OCR/VLM operation/response per FileService, no queue, excess429; source SH lock/task/slot held through delivery or cancellation. Owner/namespace/ready/hash checked before CPU work, again before any model disclosure, and after model work. Cancellation joins bounded renderer/OCR thread work before closing FD; cancelled host model requests are joined until bounded completion before releasing admission; server-side computation after a network timeout is not certified aborted. Source/quota/schema remain unchanged. Output is ephemeral and explicitly untrusted with file UUID/hash/page/source locator and engine version.

VLM host client verifies configured CORE alias using bounded `/v1/models`, disables environment proxies/redirects, uses only loopback configuration,45s total deadline,64 KiB response cap and1024 output-token cap with thinking off/temperature0. No raw image/cell/text/response or keys in logs. Strict JSON Schema constrains generation and output schemas/finish reason are validated; incomplete/unavailable output fails closed. Prompting is advisory, not a prompt-injection guarantee; no tools are exposed.

Acceptance: golden clean/noisy/blank images, scanned multi-page PDF/native comparison, exact source/page/pixel mapping, measured OCR CER/word accuracy and table-cell accuracy from actual CORE vision, uncertainty/failure handling; real namespace/resource/kernel/timeout checks and DB/HTTP owner/hash/state/delete/cancel/slow-response gates; full Vault-backed regression. Preserve metrics/versioned golden oracles and honest limitations before PASS. Rollback drains operations/removes OCR endpoints/modules, retaining prior schema/root/auth/blobs/backup identity. Production SLOs and arbitrary-language/layout accuracy remain unaccepted.
