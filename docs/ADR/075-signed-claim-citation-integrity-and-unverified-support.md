# ADR-075: Signed claim citation integrity and unverified support assessment

**Purpose:** Define D56 proof and model-assessment boundaries before implementing claim-to-citation validation.

**Date:** 2026-10-21 (Asia/Ho_Chi_Minh).

**Status:** Accepted implementation after D55 commit68e11fd/2318 related/0SKIP, distinct actual public/CORE gates and clean readonly audit. D56 IN PROGRESS; no production API or model adoption.

Existing P1 D56 depends on D51 owner-signed exact spans and D55 bounded source comparison. Estimate one internal immutable contract/policy/service, controlled signed-quote/schema/lifecycle tests, a frozen actual CORE three-claim experiment, related regression and readonly source/data/runtime audit. Risks: real quotes attached to unrelated claims, invented citation IDs, foreign/stale/tampered proof, silently omitted claims, page/claim instructions, confusing model judgments with semantic verification or treating fetch dates as publication truth. No existing accepted source/config/API/model/data/dependency/Vault/database/service change.

Caller supplies an authenticated owner UUID, explicit goal,1–8 complete claim strings (each≤1024UTF-8 bytes) and1–4 explicit D55 SourceSpan values. Validate the entire batch and every D51 signed quote before charging/admission/inference. Preserve original claim strings and complete exact quotes; no clipping, automatic excerpt selection, private context or source fetching. Assign C1…C8 and E1…E4 on the host. Reject duplicate exact spans; one snapshot may support several different claims. Complete neutral JSON prompt≤24KiB, no owner/signing key or literal angle-bracket protocol delimiters.

One unchanged CORE/fast/temperature0/max768 call,15s model/20s cooperative total. Strict JSON only claims:list, exactly every assigned claim once. Each row only claim_id/status/evidence_ids/reason. Known statuses supported/contradicted/insufficient; supported and contradicted require at leastone known unique evidence ID, insufficient may have none. Reject unknown/duplicate/omitted claim IDs, fabricated/duplicate evidence IDs, extra/winner/tool fields, nonfinite/duplicate JSON, oversized/empty reasons, model/preset/token/finish drift and whole result128KiB overflow. Return rows in original claim order, with original host-owned text and authentic quote references, not model-selected text/URL/hash. Revalidate all original spans after completion before publication.

Citation integrity means an owner-authenticated exact source quote, never proof that its claim is true. Model support classifications and reasons remain explicitly unverified assessments; semantic_validation=false and verified_freshness=null. No published claim is silently relabeled verified; no generated final answer or automatically selected winner. D57 must preserve these distinctions, validate any report citation IDs and recheck original proofs around generation; an arbitrary caller-constructed validation dataclass is not an authorization credential.

One nonqueued owned operation; existing finite quota16 global/four owner/60s charges every model attempt, including failure/cancellation/dispatch, without refund. Reuse accepted spawn/join primitives and explicit timeout.expired checks. Repeated cancellation/shutdown retain ownership until cleanup; shared evidence/model lifetime is external. Closed/uncertain evidence dependency poisons admission. Logs/repr retain metadata only. Cooperative cleanup is not a hard model-server stop SLO.

Freeze sources and actual oracles before inference. Actual experiment uses two authored signed sources and three predeclared claims: one supported G-17 restore claim, one contradicted upload quota, one absent launch-year claim. One unchanged actual CORE call; this is same-agent finite functional evidence, not live publisher fact-checking, human-independent/general semantic quality or model adoption. Preserve first failures; no post-score label changes or retries. All503 accepted D55 source/config bytes must remain unchanged. Historical fresh D52 full3534 stays separate; affected regression plus actual and readonly audit gates are required before D57.

Rollback drains/removes only this unwired service. Shared evidence keys/cache, source data, models, API/config/Vault/database/provider containers remain intact; no migration/reindex. Model changes still require owner-approved benchmark/resources/migration/rollback. D53 low coverage/null freshness and WEB-EVAL-002/WEB-INJECT-001/WEB-BROWSER-001 remain before D60.

Implementation detail: exact duplicate original claim strings are refused to avoid ambiguous repeated host IDs; complete text otherwise remains unchanged. First63 controls/two test wiring failures are preserved before new-test-only corrections to accepted budget/task helper APIs. All69 controlled PASS; actual frozen model/related/readonly gates pending.
