# ADR 093 Existing multimodal resource and context measurements

**Purpose:** Define D67 reproducible original CORE/adapter resource/context observations and current full regression before any model/resource/configuration proposal.

**Date:** 2026-10-22. **Status:** Accepted for measurement after D66 commit2d93d98, no model/runtime changes.

Existing D67/P1 depends on accepted D61–D66 native/core media, exact source clocks and original32K/parallel1 CORE. Effort one frozen workload/metric controls/finite sampling matrix/resource report/current full/read-only closure milestone. Risks: mixing CPU RSS with GPU allocation, calling sampled/lifetime maxima workload peaks or private RAM needs, invented tokenizer counts, cache/cold-start confusion, reporting nonstreaming completion wall time as TTFT/decode TPS, resource observer overhead, simultaneous benchmark/full-test contention and inferring general context reasoning from an echo protocol.

Keep qwen3.5-9b-core/mmproj/Q6_K, GPU layers99, context32768, parallel1, loopback8080 and every native limit/model/config/data/service unchanged. No model/dependency/image downloads, restarts, GPU resets or production wiring. Freeze three repeats per successful phase: ordinary text echo before; neutral authored standalone contexts with repeat counts128/2048/8192/16384/31500; three real public-speech/provided-reference sparse-frame timeline operations; ordinary text echo after. One34000-repeat overflow trial must be rejected by the unchanged application context budget. Repeat counts are fixture parameters, never claimed token counts. Query the actual existing apply-template/tokenize path before each text measurement and report backend usage separately, preserving discrepancies. A single current user turn cannot be silently truncated by fit_token_budget; overflow is an expected refusal, not model quality success/failure. Each media repeat uses its own declared synthetic principal, original clip/image quotas and one native audio/video plus three CORE image answers. No automatic retries or independent-human/general semantic/context-recall claim.

Measure per-call wall duration with the unchanged application adapters/fixedfast/T0/max512 text, unchanged image options. Preflight tokenizer wall is separate; original adapter's own token/template checks remain inside measured completion wall. Report min/median/max of three observations, not statistically established population p95/SLO. Output tokens divided by full completion wall is explicitly end-to-end output rate, never decode TPS; TTFT is NOT MEASURED because requests are nonstreaming. Original prompt-cache/warm sequential behavior remains, no cold-load benchmark claim. Literal echo verifies delivery under actual context load, not long-context reasoning or retrieval accuracy. Do not compare different models or recommend a winner.

Read exact original CORE PID/startticks identity and Linux VmRSS plus NVIDIA compute-process allocation throughout the finite run with a target200ms wait between samples. Stop/join the sampler in all outcomes; no background monitoring service or periodic upstream search. Record observed cadence/collection cost and unknown values explicitly. CPU RAM RSS includes shared/mapped pages and is not unique/private RAM; GPU compute allocation includes model/KV/workspace and is not just weights. Finite sampled minima/maxima are not true peaks or resource requirements; native512MiB is an address-space cap. Observe only matching native worker/decoder descendants of this evaluator, preserving PID/start identity and per-process RSS; no sum-as-private-memory or zero substitution for missed short workers. CORE CPU ticks are process observations, not GPU utilization. Resource unknown/changed PID/starttime/nonfinite samples refuse a complete measurement claim.

Acceptance: every predeclared delivery/overflow/media/timeline/text-recovery gate measured without hidden retries; tested strict metrics and honest timing/token/cache/RAM/VRAM limitations; all source/first failures frozen and retained; current full application regression after measurement (never simultaneous) plus final original model/data/runtime/security/read-only audit. The previous full4265/562-source D62 invocation remains historical, not relabelled with a new count. Do not mark D67 complete or advance D68 before actual full/audit closure.

Rollback removes/drains only new evaluation helpers/evidence/sampler, retaining every original source/model/config/blob/database/service, prior results and failed cohorts. Automatic ASR/VAD/TTS comparisons/selection remain separate registry work with the owner's benchmark/migration/rollback/approval gates.
