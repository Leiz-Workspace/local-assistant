# ADR 092 Provided transcript and frame timeline composition

**Purpose:** Define D66 actual speech/explicit-transcript and decoded-frame composition before implementing audio normalization and deterministic timeline joining.

**Date:** 2026-10-22. **Status:** Accepted for local composition after D65 commit a0929b4; no ASR/TTS/model provisioning or selection.

Existing D66/P1 depends on D64 decoded video clocks, D65 owner/source/frame descriptions and a source-bound supplied transcript. Effort one bounded native audio normalization capability, immutable supplied-transcript/timeline contracts, authored composite fixture, negative/clock/lifecycle tests, real audio/frame composition and readonly audit. Risks: pretending supplied text is ASR output, certifying words from source hashes, confusing stream start with first decoded sample, resampling or codec-priming clock offsets, joining another owner's/audio source, unsupported sample bounds, transcript injection, hidden time gaps and implying that independently muxed visuals depict the original speech event.

The roadmap places D66 transcript/frame joining before D68 ASR comparison. Resolve this dependency by accepting an explicitly supplied unverified transcript with exact owner/source/normalized-audio hash and sample intervals. D66 implements joining; it does not infer speech. Earlier D65 notes about the actual ASR dependency refer to the later automatic speech pipeline: MODEL-EVAL-003/D68 remains NOT EVALUATED until its own authorized benchmark/decision. No future ASR result is invented, no model is downloaded or substituted to advance this day, and no ASR/product acceptance is claimed from the local supplied-reference gate.

Use a public real-speech fixture from the official [Whisper repository pinned revision](https://github.com/openai/whisper/tree/86098128c0b4f24f0e2aa2994de830614b474227): tests/jfk.flac, exact SHA256 63a4b1e4c1dc655ac70961ffbf518acd249df237e5a0152faae9a4a836949715. Retain the original license, complete source test and retrieval/hash manifest. The upstream test attests selected phrases/timing, not a newly independently reviewed full transcript. Any supplied full reference is labelled same-agent/provided/unverified, with its own hash; never label it freshly recognized or human-independent. No microphone, camera, private recording, external service key or ASR/TTS model. The evaluation video explicitly combines public speech and authored READY/MOVING/DONE frames; those visuals are unrelated to the historical recording and never described as an original filmed event.

Normalize audio in the existing credential-free readonly/network/PID namespace, using fixed FFmpeg/probe commands and finite32MiB/30s/512MiBAS/8–9CPU/32FD/8MiB output/40s parent/8s child limits. Bound decoded frames/sample counts/output; record actual first decoded audio PTS and rational source time base, require a continuous decoded sample timeline and reject unknown/discontinuous clocks. Convert to mono signed16-bit little-endian16kHz PCM, strip tags and retain source/PCM hashes and actual sample count. Parent validates complete bounded JSON/PCM integrity without codec decoding. No whole-machine or new-container change. D66 join additionally requires known clock/consistent original clip/audio metadata; compressed priming/display edits do not become certified speech timing. The authored acceptance uses PCM audio in Matroska with an explicit zero clock; later format coverage is separate.

A pure deterministic join takes one owner, D65 video description, actual normalized audio and explicit transcript segments. Require exact owner/video-source/audio SHA associations, complete bounded NFC text, increasing nonoverlapping integer sample intervals inside observed audio length, and complete valid sparse frame timing. Map samples to relative video time using actual audio first PTS/timebase minus video origin/timebase plus sample/16000. Keep exact rational endpoints and declared origins, source hashes and provenance. Transcript words are unverified supplied text, timestamps are sample-window provenance (not word alignment). Rendering uses escaped literal strings, finite limits and no executable HTML/links/tools. It does not let a model invent times, interpolate gaps or collapse uncertainties. No additional model call is needed to manufacture a prose summary; a concise reproducible labelled speech/frame timeline is the short-clip summary.

Acceptance: source-bound real decoded speech plus original CORE sparse frames in an explicitly authored composite; frozen supplied reference/segment intervals before actual join, exact rational event times and reproducible summary; reject cross-owner/source/audio/time/sample/text/clock/schema failures, actual codec/resource/timeout/no-leak tests; preserve every first error and unchanged prior580 source/model/config/data/runtime audit. No raw media/transcript history is automatically persisted by application code; public authored evaluation artifacts are explicitly retained. Replies are untrusted/semantic validation false/confidence null; no automatic ASR, word timing, continuous motion, original-scene or production/API/UI certification. D68 candidates and all agreed models retain registry roles and approval gates.

Rollback drains/removes only new audio normalization/join components and evaluation artifacts, retaining existing source/video/image/OCR contracts, models/config/database/services and all first outcomes.
