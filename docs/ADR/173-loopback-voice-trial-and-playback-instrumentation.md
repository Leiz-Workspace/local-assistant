# ADR 173 — Loopback voice trial and playback instrumentation

**Purpose:** Fulfil the owner’s “Làm đi” request for a working browser URL after ADR170–172 qualified local buffered compute. Owner confirms Brave is on the same computer as Codex.

**Status:** Implementation/verification scope authorized by the request; optional local research surface, not product/default/model adoption or physical4second acceptance.

## Decision

Add a separate `apps/voice_trial` surface bound strictly to127.0.0.1:8092. Preserve the already passed recorder and all existing app/model/config/default/service paths. Reuse its explicit-capture/worklet assets; the new trial visibly limits capture to20seconds, which is the existing ASR contract. Only an explicit Send uploads a canonical mono16k PCM16 WAV. Microphone remains off after Stop/Cancel/Escape/tab hide/reload and is never acquired by the agent. User interactions are Vietnamese; implement English descriptions/tests/audit without speech in logs.

Use a process-random HttpOnly SameSiteStrict session cookie, exact loopback Host/Origin and same-origin FetchMetadata/custom submission-header checks; no CORS, remote binding, URL/query credentials or Vault/database changes. Admit one operation without queuing, with bounded request bodies/UUIDs, authenticated status/prepare/cancel, request-disconnect cancellation and stale-result refusal. No tool execution or history. Browser/session input is untrusted and cannot select models/files/profiles/prompts.

Expose the exact qualified research lane only: Silero v5 detector peak-copy, original complete ASR PCM/clock, Qwen3-ASR-0.6B CUDAFP32/eager/TF32off, owned CORE32K/Fast512 and Trúc Ly original CPU8/FP32 accepted reading. Existing decoders/reference/sampling/context remain unchanged. A new manifest-bound worker entry delegates directly to the original inference implementations; expand only explicit protocol budgets, not model settings. No new package/weight/download or shared-service restart.

Require explicit Prepare; never load models or capture microphone merely by opening the page. One process admits at most3preparations and24total first submitted turns (including automated public-source preflight); each worker permits24first requests, one declared1secondzero-ASRreadiness perprepare, zero retries/automatic reload. Each loaded group expires after8minutes or first resource/provenance/software failure; original worker600/900second, CPU1200second, host14GiBpreflight, aggregateworker+CORE8GiBRAM/TTS2GiB, Qwen64GiBvirtual/4GiBallocator/4.5GiBVRAM/free1.25GiB/pre-load6GiB guards remain unchanged. Prepare startup still requires original COREslot/headroom and yields gracefully if busy. Idle groups are sampled too. Cancel/disconnect joins owned work; aborting a native call retires the group and requires explicit Prepare again. No retry of a failed turn.

Use a fresh private64MiB-capped `/dev/shm` workspace for dynamic per-turn original inputs, separate detector copies, native outputs, manifests and model logs. Launch with TMPDIR=/dev/shm so existing audio conversion uses RAM-backed anonymous tempfiles. Remove user inputs/native chunks/worker diagnostics after each joined turn and all workspace content after shutdown. Retain only finite control/resource/count/timing receipts without raw audio/transcript/answer. Return one complete transcript/answer/WAV in memory; browser clears capture and playback/transcript/answer references on Cancel/tab hide or5minute TTL. No persistent storage, service worker or external request.

Browser unlocks its output AudioContext in the Send gesture, then plays the complete returned audio and reports submission→response and submission→scheduled-playback. Autoplay/context failure shows manual replay and no automatic PASS. These are browser markers, never proof of physical audibility. PC/Brave speaker first-audible requires owner observation or synchronized screen+speaker recording; no agent microphone permission/capture or declared physical PASS. Keep firstfailed/firstpassed compute cohorts immutable.

## Verification, rollout and rollback

P1 VOICE-LATENCY-AC-001 continuation. Dependencies: qualified local lane, existing explicit recorder and resource guards. Effort one isolated integration/control milestone plus bounded real HTTP/browser preflight and owner physical check. Test loopback/auth/CSRF/size/type/duplicate/busy/cancel/disconnect/TTL/error/cleanup and UI lifecycle with fake models; then freeze sources and use up to6fixed retained public inputs (4speech/2negative), at most6VAD/4ASR/4CORE/4TTS plus1declaredreadiness, through actual HTTP. Headless/browser tests do not open a real microphone. Preserve first failures; no automatic new campaign. Verify the real URL on the same computer before delivering it, leave the web surface ready for explicit Prepare, and document its process/stop command.

Do not replace the original renderer or enable production endpoints. Rollback stops only the owned trial service and model group and removes ephemeral workspaces; no data migration. Risks: response/upload/playback overhead beyond compute, cancellation races, stale output, memory contention, idle expiry and mistaking scheduled audio for physical first-audible. D60 deferred, pronunciation cycles stopped; D74product/rights/default/physical4seconds and D90release remain OPEN.
