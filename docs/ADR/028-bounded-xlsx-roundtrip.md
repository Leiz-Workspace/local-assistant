# ADR-028 — Bounded XLSX inspection and formula-preserving literal edits

**Purpose:** Specify D20 workbook fidelity, non-execution and operation ownership before implementation.

**Date:** 2026-10-18
**Status:** Accepted for localhost/one worker: 42 processor/contract/sandbox + 16 DB/HTTP/lifecycle cases; final full 587 passed in 52.87s, zero skipped. Dev-only openpyxl 3.1.5 independently reopens output; existing runtime lxml unchanged.

P1 work depends on D17 owned ready files/isolated FD parsing and D19 response-lifetime admission. Estimate one or more milestones. Risks are archive/XML expansion, ambiguous sheet/cell references, formula execution or cache corruption, style loss and cancelled/slow responses. Reuse runtime lxml; add uv-locked dev-only openpyxl as an independent reopening oracle. No new service, schema or credential.

Add authenticated `POST /files/{id}/xlsx/read` and `/xlsx/rewrite` under the existing local API. Read returns untrusted workbook sheet IDs/names, canonical cell addresses, native types/lexical values, formula source/attributes, cached values, style indices/count and merged ranges. Source UUID/hash, processor version and sheet/cell locators identify immutable source content. Strings may use shared or inline storage; rich text is readable but not editable. Styles are referenced and preserved, not rendered or resolved.

Rewrite requires exact source SHA-256 and 1–100 unique `(sheet_id, cell, kind, value)` edits in strict JSON at most 64 KiB. Edit existing literal cells only. Kinds are `string` (XML-valid text, stored explicitly as inlineStr even when starting `=`), `number` (finite representable decimal lexical string), and `boolean` (strict boolean). No formula input, new cells/sheets or arbitrary XML/paths. Refuse formula cells, all merged-range cells, rich text, metadata/unsupported cell structures, missing indices and signed packages. Preserve cell style/row/column/workbook properties. Serialize changed worksheet XML only; every other decompressed ZIP member remains byte-identical, including untouched sheets, shared strings, styles, formulas and calculation settings.

No formula/macro evaluation, remote fetch, cached-value recomputation or implicit model context occurs. Existing formulas and their cached values/attributes remain unchanged even when edited inputs make caches stale. Read/response headers explicitly report `preserved_not_recalculated`; this is not a calculation-correctness certificate. Spreadsheet applications opening downloaded files may apply their own calculation policy; this service does not execute formulas. D17 macro/external-relationship/DTD/archive bounds apply before parsing and to rewritten output.

Return bounded ephemeral XLSX attachments with private/no-store/nosniff, source UUID/hash, processor version, output hash and cache-status headers. No output persistence/quota charge or source mutation; normal reserve/upload is required to retain output. Own source SH FD, admission and task through response delivery/cancellation. Recheck owner/namespace/ready/size/hash before parsing and hash/ready afterwards; join threads before closing. Two XLSX operations/responses per service, no queue, excess429; existing PDF/DOCX gates remain unchanged, within one-worker scope.

Reuse D19 sandbox FD pattern without refactoring its PASS modules: source stdin, bounded anonymous request mounted read-only at `/request.json`, no text in argv/env, no host/private paths/network. Worker 512 MiB RAM,5/6s CPU,10s parent wall,32FD,zero core,25 MiB output; read JSON including locators8 MiB, extracted lexical text1 MiB, cell64 KiB/32767 UTF-16 units,100 sheets,50000 cells,100000 shared strings,10000 cell styles. Main/worksheet XML retains D17's2 MiB per part limit. Validate canonical A1 coordinates within Excel bounds, unique sheet/cell identities and style/string references. Reject overflow, never truncate. Strict lxml has no entity/DTD/network/huge-tree loading. Safe errors and UUID/count/version logs exclude cell/formula/edit text.

Acceptance requires golden multi-sheet Unicode/numeric/boolean/formula/cached/styled/shared-string/merged content, independent openpyxl reopening, exact formula/cache/property and untouched-part preservation; adversarial packages/limits/unsupported edits; actual sandbox/kernel/timeout checks; real DB/HTTP owner/namespace/hash/state/cancel/delete/slow-response/admission and output-size negatives; full Vault-backed regression. Rollback drains requests and removes XLSX code/endpoints; retains source journal/root/auth/blobs and earlier PASS milestones.
