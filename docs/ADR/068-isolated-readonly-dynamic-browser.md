# ADR-068: Isolated read-only dynamic browser

**Purpose:** Define the existing D50 dynamic-page browser boundary before implementation while preserving accepted model/search/fetch/API/data/services.

**Date:** 2026-10-21 (Asia/Ho_Chi_Minh)

**Status:** Accepted and implemented within local D50 scope:147 new controlled cases including13 native,2006 related PASS/0SKIP, first frozen actual public dynamic-text observation and clean readonly audit. [Acceptance](../evidence/d50-browser-acceptance.json). No production deployment or model/image download; initial capability/control failures retained.

Re-estimate after cached runtime inspection. Dependencies: existing Docker, cached browser tool image, existing host asyncio/JSON/network policy; no new model/host package or accepted application startup change. ## Proposed runtime and authority

Create only a fresh named owned ephemeral container per explicit URL, never a permanent service or reused login profile. Cached digest/pull-never, nonroot, read-only root, drop all caps/no-new-privileges,1GiB/oneCPU/256PID, bounded temporary profile/shm, no GPU/host Docker socket, no published port or shared network. Browser network namespace is none; no host socket/profile/data directory is mounted. Mount only one fixed readonly worker program; it forwards CDP over inherited pipes. The host intercepts each permitted resource and fulfills its bytes, so the browser never has a routable network channel. Do not invoke the crawler, auto behaviors, arbitrary script/command, shell URL interpolation, image/model/package download or existing service restart.

The host resource broker issues only fixed credentialless HTTPS GETs, validating the whole DNS answer/public selected pin/actual peer/original SNI/system CA through unchanged D49 networking helpers. A separate bounded resource adapter supports only document/script/stylesheet/JSON/plain text media; do not modify the accepted D49 adapter. Each resource is supplied by Fetch.fulfillRequest at request stage, with its actual status/type/body and restrictive CSP. No direct browser network, CONNECT tunnel, client headers/cookies, environment proxy, address fallback or retries. Every real TLS verification is performed by the host broker, not claimed as a browser-native network handshake. Controlled TLS seams stay separate from actual public resource verification.

Rejected the earlier CONNECT/Unix-relay proposal: opaque TLS tunnels cannot independently enforce HTTP methods, and require a needless host socket/relay mount. Host fulfillment plus network-none removes that channel entirely and prevents uncaught browser WebSocket/UDP/background traffic from reaching the server/private network. No production certificate bypass or system trust installation.

Expose only explicit navigation and bounded text/source observation. No click/type/file input/upload/execute-JS/model-selected CDP method/headers/browser arguments. Trusted fixed policy commands only. Disable downloads using Browser.setDownloadBehavior deny, deny permissions/popups/new targets/workers/frames, refuse non-HTTPS443 or non-GET requests, strip ambient authorization/cookie headers, and retain no user profile/history. [Download policy](https://chromedevtools.github.io/devtools-protocol/tot/Browser/#method-setDownloadBehavior).

Intercept every request before navigation and fulfill only permitted host-verified resources. Add a restrictive response CSP that permits bounded HTTPS/inline dynamic scripts but denies workers/frames/objects/forms and non-HTTPS connect schemes, including WebSockets. Never waive CSP/origin/certificate restrictions to get a sample working. No application-authenticated destinations or credentials. Fulfill complete bounded response bytes with fixed safe headers, no Set-Cookie/ambient authorization; preserve stricter source CSP alongside the local policy. Validate installed CDP and inherited-pipe support before scoring. [Fetch domain](https://chromedevtools.github.io/devtools-protocol/tot/Fetch/). Read title/text using fixed native DOMSnapshot/history observations, with no arbitrary JS evaluation. Only main-frame protocol redirects are allowed; later page-driven document navigation is denied. Decorative images/fonts/media, frames and workers are outside this text-only MVP. Page text/links remain untrusted and do not select another URL/tool/model.

## Proposed bounds, cancellation and acceptance

Fixed implementation budget: one nonqueued operation per adapter;30second cooperative total navigation deadline,8 concurrent resource handlers,32 HTTP requests,8MiB aggregate resource bytes/1MiB per response,2MiB CDP frame/16MiB cumulative per direction,4096 events/64 pending commands, complete text128KiB/title1024/result256KiB, bounded stderr hash/count only. Reject overflow without clipping evidence or silently increasing limits. Finalize exact worker paths/capabilities and numerical contract before native browser scoring. System DNS retains D49's cooperative joined semantics; no hard DNS cleanup SLO.

On timeout/cancel/protocol/event/budget failure, close page/browser, kill/join the exact owned container/CLI/worker/resource tasks and remove only known operation files after confirmed retirement. Do not delete unknown entries or report cleanup complete from a missing response alone. No session recovery/retry/GC policy or stateful browsing without later evaluation.

Test policy/URL/request/response/CSP/permission/download/target/schema/budget/redaction contracts; actual network-none container/runtime readonly worker mount/caps/resource identity, controlled dynamic inline/external GET rendering, POST/forms/WebSocket/worker/iframe/private destination denial, download absence, protocol/pipe loss, repeated cancellation/timeout/SIGKILL and cleanup. Freeze source/page/oracles before actual browser attempts; retain each first outcome, no quality/oracle rewriting. Separate authored TLS/pin fixtures from actual public DNS/TLS navigation. Run affected regression and readonly accepted-source/model/data/container audit; fresh full required if shared composition/dependencies change. D51 remains next only after actual D50 acceptance.

Rollback closes/removes only this ephemeral adapter/worker and known operation resources; existing15 containers/CORE/search API/fetch/model/config/Vault/database remain intact. No reindex or model selection change.

## Controlled implementation corrections before public scoring

Chromium's DOMSnapshot string interner returns -1 for an empty optional string. Accept it only for title/layout text, never required documentURL, bool, other negative or out-of-table indices. Required source binding and original native dynamic-text oracle remain unchanged. [Chromium AddString implementation](https://chromium.googlesource.com/chromium/src.git/+/684baa766f807a21c5eb92fca0af0b5ec2ac2f51/third_party/blink/renderer/core/inspector/inspector_dom_snapshot_agent.cc), [native schema](https://github.com/ChromeDevTools/devtools-protocol/blob/master/pdl/domains/DOMSnapshot.pdl). Initial malformed mock treating optional-1 as invalid remains archived; corrected mock denies-2 and explicitly proves-1 never selects the last string.

Native frame creation fails immediately. Post-source Page.frameRequestedNavigation/frameScheduledNavigation also fail, including forms, rather than waiting for an interrupted original load. The local CSP remains unchanged. Initial combined unsupported-action fixture expected a successful page and timed out at30seconds; original failure retained. Explicit native negative tests now assert denial/no extra host request/actual retirement, separately from positive external script/CSS/JSON rendering. Native cached Chromium classifies the exercised fetch as XHR; both classes were already permitted, so this is an assertion correction without new authority. POST's finite existing error is browser_method_denied. Cancellation followed by browser_cleanup_uncertain closes future admission even when the original caller receives CancelledError.

Add cumulative16MiB per CDP direction in both host and worker before scoring; individually bounded frames alone could admit excessive total traffic. No accepted source/config/dependency change or relaxation of confinement/resource/content oracles. Final controlled147 PASS/12.74s includes13 native tests; related/public/final audit remain pending and no D50 PASS follows from this subset.

Public functional candidate is the operator-provided JavaScript practice endpoint https://quotes.toscrape.com/js/, identified by its [official sandbox inventory](https://sites.toscrape.com/) as JavaScript-generated content. Freeze title/source/author-name markers, absent markers in static extraction of the same actual response, at least one real script resource and exact native/socket retirement before first public navigation. This is a functional dynamic-text example, not general browser quality/security/coverage/freshness evidence. No quote text is persisted.
