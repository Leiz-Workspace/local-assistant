## Reason and impact

[ADR-107](107-proposed-isolated-voxtral-evaluator-preparation.md) preparation is complete at commit `3549961`: all nine pinned files verified, separate CPU SDK imported and inventoried, root10.5929GiB/20GiB. Actual original-model load fit remains unknown. The accepted Qwen loader specifically restricts Thinker names and BF16; Voxtral uses other names and native strict-FP32 audio positions. Reusing or weakening those constraints would affect previously PASS code. Add an independent controller and runtime, leaving every old source byte unchanged.

This is an isolated research loader, not a production architecture/model/configuration migration. It does not establish Vietnamese support, audio competence, naturalness or any model-selection advantage. Imports and synthetic tiny-model tests cannot replace real-model measurements or the D70 auditory AC. No remote endpoint, account, credential, package or new model download is needed.
