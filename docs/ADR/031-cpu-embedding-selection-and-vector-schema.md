# ADR-031 — Measured CPU embeddings and versioned private vector schema

**Purpose:** Define D24 shortlist/runtime/measurement and collection lifecycle before dependency, model or collection changes.

**Date:** 2026-10-18
**Status:** Accepted for the defined local CPU selection/design scope. Final regression783 passed in95.11s,0 skips; real PostgreSQL/CORE/Qdrant. Selected multilingual-e5-base int8/768; production worker/collection remain undeployed.

P1 depends on D22 private source-bound chunks and D23 independent corpus evaluation. Estimate one or more milestones. Risks: weak multilingual retrieval, silent tokenizer truncation, model/version drift, GPU contention with existing CORE, cross-owner payload leakage, stale vectors after delete and accidental mutation of shared Qdrant collections. No API/ingestion/retrieval feature is accepted by installing a model.

Inventory: existing Ryzen7 7700/16 logical CPUs/AVX512-VNNI, approximately30GiB RAM; RTX4070Ti SUPER16GiB has approximately5GiB free while CORE runs. Existing Qdrant1.18.2 is shared. Evaluate CPU-only official ONNX int8 AVX512-VNNI artifacts from `intfloat/multilingual-e5-small` (384 dimensions) and `intfloat/multilingual-e5-base` (768). Both upstream model cards declare MIT. Pin exact repository revisions and SHA-256/size of model/tokenizer files; retain upstream license metadata/card references. Add only dev/benchmark `onnxruntime`/`tokenizers` via uv; no Torch/CUDA stack, runtime service, automatic startup/download or changes to CORE configuration. Public downloads explicitly provision only these trusted pinned artifacts into ignored model directories; no private Hub credentials or remote model code.

Use `CPUExecutionProvider`,2 intra-op threads/1 inter-op thread, sequential execution, batch≤4, max512 tokens including special tokens and English `query: `/`passage: ` prefixes even for Vietnamese. Attention-mask mean pool and L2 normalize; cosine/dot on unit vectors. Validate dimensions/finiteness/nonzero norm. Tokenize without truncation and reject empty/overlong lexical inputs; never silently drop D22 source text. D22 byte budgets are not token budgets. D25 must preflight actual tokenizer counts and design any smaller source-preserving chunk version; v1 row overflow remains a rejection. Output vectors stay in benchmark memory, never model context or permanent user index.

Before measurement freeze a handwritten synthetic retrieval corpus with Vietnamese, English and cross-language query/source pairs plus related distractors and exact relevance labels, separate from D23 reconstruction goldens. Gates: Recall@3≥0.90, MRR@10≥0.80 overall; Recall@3≥0.80 in each declared language group; peak child RSS≤2GiB and warm single-query p95≤500ms on this local2-thread CPU drill. Report every rank/miss/metric, cold load/artifact size/RSS/warm latency, token counts and overflow refusal, provider/runtime/model/corpus hashes. No public-benchmark/general-accuracy/load SLO claim. Choose minimum observed peak-RSS eligible candidate within0.05 MRR@10 of the best eligible candidate; otherwise highest MRR. Do not tune relevance labels or thresholds after observing results; expand milestones if gates fail.

Proposed collection family `la_chunks_<model-fingerprint>_v1`, named vector `dense`, fixed selected dimensions/Cosine/on_disk=true, one replica/shard on existing instance. Model fingerprint binds repository/revision/model+tokenizer hashes, prefixes/pooling/normalization/token cap/runtime format/package versions; do not mix models/tokenizers/chunker versions in an index generation. No production collection is created in D24. An explicit design probe may create only a fresh UUID-named `la_d24_probe_...` empty collection, validate schema/payload indexes and delete exactly that owned name; existing collection names/config/count fingerprints must remain unchanged. Probe credentials come from existing Vault only in parent memory, loopback6333/no proxies/redirects, never argv/logs/artifacts. Read-only key can inventory, admin key used only for this scoped probe; shared keys are not tenant authorization.

Required server-derived payload: owner_id/namespace_id/file_id UUID; source_sha256/chunk_id/chunker_version/processor/model_fingerprint/index_generation keyword; visibility/private, content_trust/untrusted, readiness/active, locator/span/section/quality references. Index owner_id with UUID tenant index, namespace_id/file_id UUID, generation/model/chunker/source hash/chunk_id/state keywords. Omit source text, credentials and inferred ACL grants from vector payload. Query authorization must combine trusted owner+namespace+active generation/model constraints and then rehydrate/revalidate source ready/hash/ownership from PostgreSQL before returning text; never trust caller labels or Qdrant alone. Detailed search adapter remains D26.

Point ID is UUIDv5 of trusted scope/file/source-hash/chunk/model/index-generation identity; chunk IDs remain descriptive. D25 must implement a durable ingestion journal/outbox, immutable source/hash/version idempotency, bounded embedding admission, pending→active generation publication only after source revalidation, and tombstone/retry/reconciliation. No distributed transaction across PostgreSQL/Qdrant is claimed. Delete hides source in PostgreSQL immediately; subsequent searches recheck and cannot expose stale points; physical vector removal is retryable and tracked. Update/reindex builds an isolated generation, publishes after complete validation and retires old generation; no cross-owner adoption. Old unbound data is never inferred/adopted.

Rollback: drain benchmark/worker operations; remove ephemeral probe only if owned; retain source/auth/root/schema/shared collections and current CORE. Future production migration uses new collection/model generation and explicit cutover, retaining old collection for reversible rollback; deleting user collections requires a separately authorized lifecycle operation. Encryption/backups/off-host DR/multiworker/load remain separate deployment gates.

Sources: [official small card](https://huggingface.co/intfloat/multilingual-e5-small), [official base card](https://huggingface.co/intfloat/multilingual-e5-base), [ONNX Runtime Python API](https://onnxruntime.ai/docs/api/python/api_summary.html), [tokenizer API](https://huggingface.co/docs/tokenizers/api/tokenizer), [Qdrant collections](https://qdrant.tech/documentation/manage-data/collections/), [multitenancy](https://qdrant.tech/documentation/manage-data/multitenancy/). Selection is a local measurement inference, not an upstream quality guarantee.
