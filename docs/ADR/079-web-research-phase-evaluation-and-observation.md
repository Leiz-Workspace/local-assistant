## Decision and sequencing

D60 is the existing web research phase gate: an end-to-end researched artifact with tested sources. Before claiming acceptance, execute explicitly frozen evaluation tasks: T01 diagnose D53 provider/source gaps and separately repeat the unchanged eight-query/four-source corpus; T02 broader dated-source/bilingual coverage and integrated hostile evidence→claim→report→export evaluation; T03 review official current browser runtime/release/security evidence and exact cached compatibility/resource/rollback constraints; T04 actual original CORE→selected owned SearXNG→public source→signed claim/report→native DOCX/PDF→durable archive with complete original provenance, unknowns and all-page render review; T05 appropriate full regression and readonly model/data/container audit. No next-day advance from code or an incomplete/failed gate. Retain all first errors/outcomes and distinguish protocol delivery, functional usefulness and production promotion.

P1 depends on D47–D59 and WEB-EVAL-001/002, WEB-INJECT-001, WEB-BROWSER-001. Estimate one finite diagnostics/corpus/actual phase trial/full regression milestone; re-estimate after observed causes. Risks: post-score label or threshold changes, unsafe parser relaxation, retrying a failed upstream invisibly, raw restricted snippets/pages persistence, expired proof reuse, static fixtures labeled live research, broad model/browser quality or security claims from narrow examples. Existing source/API/config/dependencies/services/Vault/database/model/data remain unchanged unless an actual failure demonstrates a separately recorded necessary repair. No new package/image/model download or browser runtime adoption in this evaluation.
