# ADR-076: Reproducible cited Markdown and expiring report receipts

**Purpose:** Define D57 evidence-backed Markdown composition and future export integrity before implementation, preserving unverified model status and accepted sources.

**Date:** 2026-10-21 (Asia/Ho_Chi_Minh).

**Status:** Accepted implementation after D56 commit16de29b/2388 related/0SKIP, distinct actual3/3 authored claim labels, preserved original bare-array failure and clean readonly audit. D57 IN PROGRESS; no public endpoint or broad research readiness.

Existing P1 D57 depends on D51 signed quotes and D56 complete claim assessment. Estimate one report contract/policy/service plus controlled rendering/proof/cancel tests, frozen actual CORE→report experiment, related regression and readonly final audit. Risks: free-form generation inventing uncited facts, rendering hostile Markdown/HTML as report instructions, silently omitting contradictions/unknowns, forged caller-constructed assessment dataclasses, evidence expiry during generation, changing bytes after export approval and confusing authentic citation identity with semantic truth. No accepted source/config/model/API/data/Vault/database/dependency/service change.

Generate from an authenticated owner UUID, explicit goal, complete original claims and signed SourceSpans. Own an accepted D56 validator instance; make exactly its one original CORE/fast/temperature0/max768 assessment, no additional report-drafting model call or source fetch. Bind returned assessment owner/goal/original claim text/order/known citation IDs/full source references/status metadata to freshly authenticated inputs. Recheck source proofs before and after rendering; refuse fabricated/changed/expired assessment evidence. A caller-constructed immutable dataclass is not an authorization credential.

Use a deterministic host template. Preserve complete original goal/claims/reasons/quotes/URLs/titles/date declarations inside dynamically sized text fences, so hostile headings/HTML/backticks/citation syntax remain source data. Only host Cn/En labels and fixed headings/limitations occur outside data fences. Separate supported/contradicted/insufficient sections, keeping every claim and authentic E-ID reference. Include original final URL, UTC fetch time, exact span/hash/source snapshot/date provenance. Publication/freshness remain unknown; labels/reasons remain model_unverified. No source winner, invented connective factual prose, silent clipping or full-search-completeness claim.

Reproducibility means identical Markdown bytes/hash for the same authenticated complete assessment/provenance; it does not promise deterministic model outputs or identical future source acquisitions. Canonical assessment digest omits owner ID, and report Markdown contains no owner/signing key. Whole Markdown≤128KiB and canonical receipt≤256KiB; overflow refuses publication. No raw source/report persistence by this service.

P1 prerequisite for D58 exports: issue a process-scoped owner-bound HMAC receipt over every complete report field, including Markdown/hash, assessment/provenance/digest and deadline. New per-service ephemeral32-byte key, never model context/log/persistence; deadline no later than minimum original source proof and now+300s. Verify exact owner/receipt/content/time/shared-source lifetime before reuse/export, constant-time MAC comparison. Hashes alone are content identity, not authorization. Report-service shutdown revokes receipts, joins owned work and closes only its own validator; shared evidence keys/cache/models remain externally owned. No durable/cross-worker receipt, recovery or reauthorization is implied; D59 evaluates those needs explicitly.

One nonqueued outer operation/25s cooperative total. Accepted inner D56 finite16-global/four-owner/60s quota charges the single assessment attempt without refund; outer dispatch before assessment charges none. Reuse accepted task spawn/join primitives; repeated cancellation/shutdown retain ownership until model cleanup. Source closure/clock uncertainty poisons admission. Metadata-only logs, no queries/claims/quotes/URLs/owners/native/model error text. No automatic retries, browser/provider/tools, private memory/workspace context or additional model choice.

Freeze code/claims/quotes/status/citation/render/receipt/one-model oracles before the actual authored experiment. Keep fixture/same-agent measurements distinct from actual publisher research or human-independent/general semantic quality. Test exact byte reproducibility, all statuses/limitations/provenance, hostile fenced data, whole result limits, forged/foreign/changed/expired/cross-instance receipts, proof changes around rendering, quota, dispatch/deadline/suppressed cancellation/shutdown/redaction. All508 accepted D56 source/config bytes remain unchanged; current affected regression and actual/readonly gates precede D58. Historical D52 full3534 stays separate. D53 quality gaps/before-D60 follow-ups remain.

Rollback drains/removes only this unwired report facade, owned validator and report receipts. Shared sources/cache/config/models/API/Vault/database/provider services remain intact; no migration/reindex. No model replacement/download or new package/container is authorized by this decision.
