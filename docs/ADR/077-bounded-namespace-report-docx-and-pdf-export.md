# ADR-077: Bounded namespace report DOCX and PDF export

**Purpose:** Define D58 source-authenticated artifact export, native runtime boundaries and render acceptance before implementation.

**Date:** 2026-10-21 (Asia/Ho_Chi_Minh).

**Status:** Accepted implementation after D57 commit1959b18/2441 related/0SKIP, first actual one-CORE/three-claim/two-reference report and clean readonly audit. D58 IN PROGRESS; no production endpoint or broad research-readiness claim.

Existing P1 D58 depends on D57 owner-bound report receipts and D56 complete claim/source assessments. Estimate an export contract/policy/service, one bounded native namespace adapter/worker, controlled/native/cancel/proof tests, a frozen original CORE→report→both-format experiment, full page rendering/visual review, affected regression and readonly audit. Risks: forged/stale report, losing references/unknowns, raw Markdown/HTML becoming document actions, hostile imported Office/PDF structures, external relationships, network/profile/credential leakage, runaway native process trees, missing glyphs/clipped text and exporting stale evidence after native work. Preserve all513 accepted D57 source/config bytes, models, API, database, Vault, original containers and data.

Use cached project python-docx1.2.0/pypdf6.21.1 and installed server LibreOffice26.2.6.3/Poppler/fonts/bubblewrap. No PyMuPDF/reportlab/WeasyPrint, new package/model/image download, dependency/lockfile change or existing service restart. python-docx is currently a development dependency; this unwired local export requires the existing development runtime and must refuse unavailable dependencies rather than silently install/promote them. Production packaging needs explicit evaluation before wiring an endpoint.

Export accepts only an authenticated owner and a D57 report verified by its issuing service. Check receipt/proof time before any model/native/file work and again after native cleanup, before publication. Do not accept caller paths, arbitrary formats/templates/options/commands, imported Office/PDF bytes or standalone Markdown as authorization. One fixed DOCX+PDF batch, no model/source/browser/provider call during export. Use a deterministic host block projection of the complete authenticated assessment, preserving every original claim/status/reason/exact quote/URL/hash/fetch-time/date claim and explicit limitations. No factual rewrite, source winner, semantic/freshness promotion or silent clipping.

Create DOCX using fixed styles and escaped text nodes only, no user HTML/Markdown parser, links, macros, embedded executables, imported templates or external relationships. Letter portrait/one-inch margins, black title/headings, readable Noto Sans and normal paragraphs, no decorative rules/cards. Preserve Unicode text; reject XML-unrepresentable input before output. Native PDF derives only from this newly generated trusted DOCX. Use a fixed Writer PDF filter without forms/bookmarks/notes or arbitrary selection, retaining all pages. Reopen ZIP/XML/DOCX and PDF to verify complete source references, page/size bounds and absence of active/external document features before returning bytes. Output hashes identify exact artifact bytes, not semantic truth or cross-version PDF byte determinism.

Reuse accepted bubblewrap command construction and readonly payload bootstrap without changing them. The new command alone permits a64MiB private writable tmpfs, read-only public font/LibreOffice system configuration, fixed UID/GID65534 and fixed cache/profile environment. Keep unshare-all/no network, private PID/IPC/user namespace, cap-drop ALL, clear environment, readonly system/runtime/source mounts/root and die-with-parent. No host output directory, original desktop profile, secrets, model/config mounts, shared writable volume or package/daemon/container change. All Office intermediates/profile/cache live only inside the namespace and disappear on teardown; return bounded bytes through owned pipes.

One trusted worker applies per-process2GiB address-space/20s CPU/8MiB file/64FD/core-dump-zero limits, strict128KiB input and fixed style/block schema. Both-format native batch wall20s, parent export25s cooperative total, bounded9MiB stdout/64KiB stderr; DOCX≤2MiB/PDF≤4MiB/32pages, no output clipping. These are per-process/native bounds, not a cgroup aggregate-RSS guarantee. Capture stderr only as size/hash, never raw source/native text. Parent joins owned process/session/pipes/selector and the namespace after failure/cancellation/timeout; repeated async cancellation waits for the owned synchronous supervisor thread. No late process publication or automatic retries. Cleanup uncertainty poisons admission.

Export has one nonqueued operation and separate existing16-global/four-owner/60s quota; failures/cancellation/dispatch after native admission are charged without refund. Shutdown joins only owned export work and never stops the issuing report service/shared evidence/model/provider. No persistent server artifact store, recovery lease or cross-worker authority; D59 evaluates long-run retention/resume. Generated bytes remain owner-bound in memory until an authorized caller explicitly stores/downloads them.

Follow PDF/documents style and render-review guidance. This project has no bundled workspace dependency loader/runtime or pdf2image; preserve the existing uv runtime. The documents verify_render guide provides the manual dedicated-profile LibreOffice+Poppler path. Native namespace generation plus independent all-page Poppler PNG inspection/text/XML checks supplies local artifact acceptance without installing project dependencies or using an existing desktop profile. Inspect every final sample page at native readable resolution, fix layout before freeze/scoring or preserve a failed cohort before repairs. Test Vietnamese/English, all statuses/unknowns/citations, hostile text, size/page/format/metadata bounds, owner/proof expiry, no network/host writes, native timeout/cancel/process cleanup and unavailable dependencies. Do not claim unseen script/layout support or general security from finite examples.

Freeze code/source/claim/citation/format/native/cleanup/original CORE call oracles before the actual integration experiment. Same-agent authored sources remain distinct from live publisher research or human-independent semantic quality; preserve all first failures. Actual native content and complete visual review, affected regression and readonly audit gates precede D59. Historical fresh D52 full3534 remains separate. D53 low coverage/null freshness and before-D60 quality/attack/browser follow-ups remain unresolved.

Rollback drains/removes only this unwired export facade/native adapter/worker; temporary namespace state is retired, shared report/evidence receipts and original services remain externally owned. No source data migration, reindex, model change or database/Vault mutation.
