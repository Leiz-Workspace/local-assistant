## Behavior and authority

`ReadOnlyBrowser.navigate(url)` accepts one explicit public HTTPS URL and returns complete bounded native layout text, title, actual final source and resource hashes after cleanup. It is an internal port, unwired to the accepted API/model/tool dispatch. Construction starts nothing. Content remains untrusted; semantic validation is false.

Each operation starts a fresh digest-pinned cached Browsertrix tool container using the actual Brave Origin binary, Chrome/149.0.7827.155. No pull, package/model download or host browser/profile. Network none, nonroot, readonly root, drop all caps, no-new-privileges, one CPU/1GiB/256 PIDs, bounded temporary profile/shm; only the fixed readonly worker is mounted. No published port, host socket, shared service network, GPU or credentials. Native Chromium sandbox is unavailable under this confinement; explicit `--no-sandbox` relies on outer Docker isolation. It is not a VM, exploit-resistance certification or evidence of current browser security. [WEB-BROWSER-001](WEB_RESEARCH_BACKLOG.md) is P1 before D60 production promotion.

The browser has no routable network. Fixed trusted CDP interception asks a separate host adapter for credentialless GET document/script/stylesheet/XHR/Fetch resources. Unchanged D49 helpers enforce complete DNS public filtering, numerical selected pin, actual peer, original SNI and system CA. The host supplies complete bytes/status and safe headers; source CSP/CORS restrictions remain and local restrictive CSP is added. TLS authenticity belongs to the host broker. Cookies/auth, arbitrary commands/JS evaluation, clicks, typing, uploads, downloads, login profiles, workers, frames, forms, popups and page-driven navigation receive no authority. Decorative resources are denied. GET can still have remote side effects; no universal remote-site guarantee.

Limits:30s cooperative operation,32 requests/eight active handlers,1MiB per response/8MiB aggregate,three redirects,2MiB CDP frame/16MiB cumulative per direction,4096 commands/events/64 pending commands,128KiB text/1024 title/256KiB result. No clipping, retries or silent fallbacks. DNS cancellation retains D49's joined cooperative semantics. Cleanup uncertainty retains private known state and closes admission; unknown leftovers are never deleted automatically. Killing the whole host process/daemon outage can require later operator recovery.
